# Aplicações Web

## Objetivo

Desenvolvimento de projetos web para prática e aplicação de conceitos de programação, interface e integração com serviços.

## Tecnologias

**HTML • JavaScript • APIs • Git • GitHub**

## Conhecimentos aplicados

- Estruturação de páginas.
- Manipulação de elementos com JavaScript.
- Consumo de APIs.
- Tratamento e apresentação de informações.
- Versionamento com Git.
- Análise e correção de erros.

## Evolução

Os projetos são utilizados para aprimorar conhecimentos em aplicações web, integração entre sistemas e desenvolvimento de soluções voltadas a necessidades reais.
