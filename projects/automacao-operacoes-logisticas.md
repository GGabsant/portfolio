# Automação de Operações Logísticas

Projeto desenvolvido para centralizar diferentes rotinas operacionais em uma interface única e simples de utilizar.

## Objetivo
Reduzir atividades manuais e facilitar a execução de diferentes automações por meio de módulos independentes.

## Competências aplicadas
- Python
- Automação de processos
- Selenium
- Interface gráfica
- Integração com planilhas
- Tratamento de erros
- Organização modular
