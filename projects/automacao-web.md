# Automação Web e Coleta de Dados

## Objetivo

Automatizar a navegação em aplicações web e transformar informações encontradas em dados estruturados para uso operacional.

## Funcionalidades

- Navegação automática entre páginas.
- Paginação e rolagem dinâmica.
- Identificação de elementos utilizando seletores.
- Extração de múltiplos campos.
- Tratamento de dados com expressões regulares.
- Esperas inteligentes para elementos dinâmicos.
- Registro estruturado das informações coletadas.

## Tecnologias

**Python • Selenium • WebDriver • Regex • Google Sheets**

## Competências demonstradas

- Troubleshooting.
- Análise de comportamento de aplicações web.
- Manipulação de dados.
- Automação de processos.
- Tratamento de exceções.

## Código-fonte

A implementação completa é mantida em repositório privado. A apresentação pública foi criada para demonstrar competências técnicas sem expor informações sensíveis.
