# Site Institucional — Transporte e Logística

Projeto de desenvolvimento web realizado **em colaboração com outro desenvolvedor**, voltado à apresentação institucional de uma empresa do setor de transporte e logística.

## Objetivo

Criar uma presença digital moderna e organizada, facilitando o acesso a informações institucionais, parceiros, áreas de atuação, oportunidades e canais de contato.

## Elementos desenvolvidos no projeto

- Página institucional responsiva
- Estruturação e organização visual das seções
- Navegação por menu
- Apresentação de empresas parceiras
- Chamadas para orçamento e oportunidades
- Componentes visuais e organização de conteúdo
- Ajustes de interface e experiência do usuário

## Tecnologias e competências demonstradas

**HTML • CSS • JavaScript • Desenvolvimento Web • UI • Trabalho em equipe**

## Participação

Projeto desenvolvido em colaboração, com participação no desenvolvimento e construção da solução web.

> O portfólio apresenta o projeto como experiência prática de desenvolvimento. Códigos, dados internos e materiais que não devem ser publicados permanecem privados.
