# Como substituir o portfólio atual

## Método mais simples — pelo site do GitHub

1. Abra: https://github.com/GGabsant/portfolio
2. Clique em **Add file > Upload files**.
3. Arraste para a página o conteúdo desta pasta, mantendo as pastas `assets` e `projects`.
4. Confirme o commit.
5. O novo `README.md` substituirá a apresentação atual.
6. Depois de confirmar que tudo está correto, os arquivos `.svg` antigos da pasta `assets` podem ser apagados, pois não são mais utilizados.

## Importante

Os arquivos PNG deste pacote são cópias diretas dos screenshots originais enviados, sem a compressão que causou a perda de qualidade no portfólio anterior.
